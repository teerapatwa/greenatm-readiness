# sample-data — ชุดข้อมูลตัวอย่าง (golden set)

> ⚠️ **SYNTHETIC ทั้งหมด** — สร้างขึ้นเพื่อการสาธิตเท่านั้น **ไม่ใช่ข้อมูลจริงขององค์กร**
> ทุกไฟล์ในโฟลเดอร์ `evidence/` ขึ้นต้นด้วยแบนเนอร์กำกับไว้แล้ว และแอปต้องแสดงแถบ
> "ข้อมูลตัวอย่าง (Mockup)" ค้างไว้ทุกหน้า ห้ามซ่อน

สร้างตาม `PLAN.md` §6.2 · หลักการคือ **ปั้นข้อบกพร่องลงในข้อมูลก่อน แล้วค่อยเขียนโค้ดให้จับได้**
ไม่ใช่เขียนเทสต์ให้ผ่านโค้ดที่มีอยู่

## สิ่งที่อยู่ในนี้

```
sample-data/
  manifest.json      กอง · ผู้ใช้ · ค่า app_setting · 12 รายการ (เกณฑ์ · น้ำหนัก · milestone · หลักฐาน)
  evidence/          เอกสารหลักฐาน 24 ชิ้น (E-001 … E-024)
  README.md          ไฟล์นี้
```

| | |
|---|---|
| รายการติดตาม | **12** (ข้อคำถามประเมิน 7 · โครงการ 5) |
| น้ำหนักรวม | **100** (ตรวจแล้วตอน generate) |
| น้ำหนัก milestone ในแต่ละรายการ | รวม **100** ทุกรายการ (ตรวจแล้ว) |
| เอกสารหลักฐาน | **24 ชิ้น** |
| วันอ้างอิงของชุดข้อมูล | **15 ก.ย. 2569** (`as_of_date`) |

## ⚠️ กฎข้อเดียวที่ห้ามละเมิด

`manifest.json` มีฟิลด์ **`expected_tier`** · **`expected_cases`** · **`_defect`**

> **ห้ามส่งฟิลด์เหล่านี้เข้า context ของโมเดลเด็ดขาด**
> มันคือเฉลยสำหรับ `verify.py` เท่านั้น — ถ้าหลุดเข้าไป agent จะอ่านคำตอบแทนที่จะประเมินเอง
> และ AC-06 จะพิสูจน์อะไรไม่ได้เลย
>
> ตัวไฟล์ใน `evidence/` **ไม่มี**ฟิลด์เหล่านี้โดยตั้งใจ — agent เห็นแค่เนื้อเอกสารล้วน ๆ

## ข้อควรระวังตอนเขียนโค้ด

1. **`document_date` ของ E-021 เป็น `null` โดยตั้งใจ** — ระบบต้องถามหาวันที่
   **ห้าม fallback ไปใช้ `upload_date`** เด็ดขาด (นี่คือ AC-03)
2. **เกณฑ์เอกสารล้าสมัยคิดจาก `document_date` เทียบ `as_of_date`** ไม่ใช่เทียบวันที่รันจริง
   ไม่งั้นเทสต์จะพังเมื่อเวลาผ่านไป
3. **ชั้น C และ D ห้ามดันตัวเลข Verified ขึ้นไม่ว่ากรณีใด** — บังคับเพดานนี้ในฝั่ง backend
   ไม่ว่าโมเดลจะเสนออะไรมา (ถ้า TF5 ไม่ผ่าน ข้อนี้คือทางรอด)
4. **A-02 คือเคสที่ทั้งระบบตั้งอยู่บนมัน** — ถ้าตัวเลข Verified ของ A-02 ขยับแม้แต่นิดเดียว
   แปลว่ากติกาสองตัวเลขพัง

## สร้างใหม่

ชุดนี้เขียนด้วยมือ ไม่ได้สุ่ม — แก้ `manifest.json` และไฟล์ใน `evidence/` ได้โดยตรง
ถ้าแก้แล้ว ต้องตรวจสองอย่าง: **น้ำหนักรายการรวม 100** และ **น้ำหนัก milestone ในแต่ละรายการรวม 100**
