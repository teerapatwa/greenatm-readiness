## กติกาที่ห้ามหลุด

ข้อพวกนี้อยู่ในแผนแล้ว แต่เป็นจุดที่พังง่ายที่สุดตอนลงมือ

1. **โค้ดคำนวณทุกตัวเลข โมเดลไม่คำนวณ** — agent ตัดสินแค่ว่า *หลักฐานพอหรือยัง* ไม่เคยตัดสินว่า *คะแนนเท่าไร*
2. **สองตัวเลขห้ามรวมกัน** — งานคืบหน้า / ยืนยันด้วยหลักฐาน แสดงคู่กันเสมอ ขนาดเท่ากัน
   `KpiPair` ต้องไม่มี prop ให้ส่งค่าเดียว
3. **ชั้น C และ D ห้ามดันตัวเลข Verified ขึ้น** ไม่ว่าโมเดลจะเสนออะไรมา — บังคับใน backend
4. **เอกสารไม่มีวันที่ → ถาม ห้าม fallback ไปใช้วันที่อัปโหลด** (AC-03)
5. **ข้อความที่ไม่มีตัวอ้างอิง → export ไม่ผ่าน โยน error** ไม่ใช่เตือนแล้วปล่อย (AC-10)
6. **`expected_tier` / `expected_cases` / `_defect` ใน manifest ห้ามส่งเข้า context ของโมเดล**
   — เป็นเฉลยสำหรับ `verify.py` เท่านั้น ถ้าหลุดเข้าไป AC-06 พิสูจน์อะไรไม่ได้
7. **ห้ามอ้างว่าต่อโมเดลสำเร็จถ้ายังไม่ได้ทดสอบ** — ถ้าใช้ mock ต้องประกาศบนจอ
